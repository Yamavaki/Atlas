# Créditos e fontes

Atlas é distribuído sob a GPL-3.0.

O código atual foi escrito para este projeto. Ele usa ideias e técnicas publicadas pelos projetos abaixo, que também são a base planejada para as próximas etapas:

- **Fantasy Map Generator**, de Max Haniyeu (Azgaar) — licença MIT. Referência para o gerador de região.
- **TownGeneratorOS (Medieval Fantasy City Generator)**, de Oleg Dolya (Watabou) — licença GPL-3.0. Referência para o gerador de cidades.
- **Generating fantasy maps**, de Martin O'Leary, e **Polygonal Map Generation**, de Amit Patel (Red Blob Games) — referências de técnica.

Quando código desses projetos for incorporado, os avisos de copyright originais serão mantidos nos arquivos correspondentes.
